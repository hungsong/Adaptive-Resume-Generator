# 自适应简历生成器 / Resume Matcher

一个面向 Windows 的本地求职工作台：接收浏览器采集到的岗位，先做意向匹配度评分，再根据个人履历原文生成岗位定向的文字简历。

原则很简单：**只优化表达，不创造事实。**

> 第一次使用请先看 **[用户教程](用户教程.md)**。教程按“解压发布包 → 安装扩展 → 配置 API → 采集岗位 → 生成并导出”的顺序编写；本项目完整参考手册见 **[使用说明](使用说明.md)**。

## 核心能力

- 浏览器遍历岗位后实时回传，岗位工作台支持搜索、筛选、排序和来源链接。
- 桌面端 AI 意向评分，区分推荐、复核与淘汰；默认只在你勾选岗位后生成文字简历，也可选完整流水线自动处理推荐岗位。
- 个人履历使用一整段自由文本，也支持从 Word / PDF / Markdown / TXT 抽取原文。
- 精准 / 标准 / 委婉三档表达强弱，所有生成内容附原文证据并通过本地事实校验。
- 岗位与文字简历一一留存，支持逐岗位导出 Word、Markdown 或 Excel。
- 多角色工作区、浅色 / 深色主题、生成前本地复用审计（复用不消耗模型额度）。

## 获取与运行

### 普通用户：使用 Windows 发布包

从 GitHub Releases 下载 Windows 发布包，解压到普通文件夹后双击 `自适应简历生成器.exe`。发布包已经包含 Python 运行环境和桌面端依赖，不需要你自己安装开发环境。

详细步骤见 **[用户教程](用户教程.md)**。

### 开发者：从源码运行

- Windows 10 / 11
- Python 3.10+
- PyQt5 桌面界面
- 兼容 OpenAI 协议的模型接口（默认 DeepSeek）

```powershell
python -m pip install -r requirements.txt
python main.py
```

也可以双击 `启动.cmd`。首次启动会要求创建或导入一个角色，然后到「设置」填写接口地址、模型和 API Key。

## 浏览器采集

BOSS 直聘岗位遍历所需的浏览器扩展已随仓库提供在 `browser-extension/`，不需要再单独下载。

首次使用：

1. 在 Edge 打开 `edge://extensions/`（Chrome 使用 `chrome://extensions/`），开启开发者模式。
2. 点击「加载解压缩的扩展」，选择本仓库的 `browser-extension/` 目录；已安装过则直接点击「重新加载」。
3. 打开并登录 BOSS 直聘，再启动本程序。进入「岗位工作台」后应显示「浏览器桥接：已连接」。

扩展支持两种接入方式：

- **实时桥接**：桌面端下发开始、暂停、停止扫描指令，扩展逐岗回传完整 JD、公司、城市、薪资、经验学历和行业等元信息。
- **离线 JSON**：扩展导出 `schema_version=1`、`jobs[]` 格式的完整 JSON，再通过「导入扩展 JSON」进入岗位工作台。

`browser-extension/` 是包含桌面桥接和完整 JSON 导出的联调版本，可能与公开上游 `BOSS-Auto-Job-Extension` 当前分支存在差异。扩展的 API Key、筛选条件和扫描记录只保存在浏览器扩展私有存储中，不随仓库上传。

完整的扩展安装、桥接检查和失败排查见 **[用户教程](用户教程.md)**。

## 本地数据与隐私

以下内容只保存在本机，并已从 Git 仓库排除：

- `config.json`：接口地址、模型与 API Key
- `data/`：角色、履历、岗位池、评分、文字简历和备份
- `logs/`：运行日志

「设置 → 本地数据 → 清空所有本地数据」可以在输入「清空」后恢复首次使用状态。默认保留 `config.json`，也可以在确认弹窗中选择一并删除。
