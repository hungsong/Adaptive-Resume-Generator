# BOSS 采集扩展

这是随「自适应简历生成器」分发的 Edge / Chrome Manifest V3 扩展，用于在你已登录的 BOSS 直聘页面中遍历岗位并读取完整 JD。

## 安装

1. 在 Edge 打开 `edge://extensions/`，或在 Chrome 打开 `chrome://extensions/`。
2. 开启「开发者模式」。
3. 点击「加载解压缩的扩展」，选择本目录。
4. 打开并登录 BOSS 直聘。
5. 启动桌面程序后，在「岗位工作台」确认浏览器桥接已连接。

更新扩展文件后，需要在扩展管理页点击「重新加载」。

## 工作方式

- 实时桥接：桌面程序下发开始、暂停和停止指令，扩展逐岗回传完整岗位信息。
- 离线导出：也可以在扩展面板中导出完整 JSON，再从桌面程序导入。
- 实时桥接时，扩展只负责采集，不调用模型、不自动收藏、不自动投递。
- 评分与文字简历生成全部由桌面程序完成。

完整使用步骤见上级目录的 `用户教程.md`。
